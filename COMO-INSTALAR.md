# Instalar GoldenEye VR no Quest

## Download

**[Baixar o APK 0.5.13 para Quest](https://github.com/ricardofilhorh-rgb/goldeneye-vr-quest/releases/download/v0.5.13/GoldenEye-VR-v0.5.13.apk)**

O link baixa o aplicativo. A confirmação de instalação depende das permissões e da versão do sistema do Quest. O APK não contém a ROM do GoldenEye 007.

## Pelo próprio Quest

1. Abra o link acima no navegador do headset e baixe o APK.
2. Abra **Arquivos → Downloads** e selecione o arquivo `GoldenEye-VR-v0.5.13.apk`.
3. Use **Abrir com → Instalador de pacotes**, se necessário, e **Instalar**, quando o sistema permitir.
4. Se a instalação estiver bloqueada, siga o método com SideQuest abaixo. Um link na web não altera as permissões do headset.

## Com SideQuest no computador

1. Prepare o Quest para instalar aplicativos externos: [guia do SideQuest](https://sidequestvr.com/setup-howto).
2. Conecte o Quest por USB e aceite no headset a autorização de depuração, se solicitada.
3. No SideQuest, use **Install APK file from folder** e escolha o APK baixado.
4. Após a instalação, abra a biblioteca do Quest e procure **GoldenEye VR** em **Fontes desconhecidas**.

## Primeira abertura

1. Copie sua própria ROM do cartucho **GoldenEye 007 USA/NTSC-U** para **Download** no Quest. Formatos aceitos: `.z64`, `.v64` ou `.n64`, com 12.582.912 bytes.
2. No launcher GoldenEye VR, use **Choose ROM file...**, selecione o arquivo e aguarde **GoldenEye 007 (USA) - OK**.
3. Marque **Stereo VR (3D play)** para a experiência imersiva.
4. Para jogar online, use **Play → Multiplayer...** antes de **START**, conforme o [guia da sala](README.md#jogar-com-um-amigo).

## Atualizar

Instale o APK por cima do GoldenEye VR anterior. A versão oficial mantém as configurações ao atualizar. Todos os jogadores desta publicação usam a versão **0.5.13**.
