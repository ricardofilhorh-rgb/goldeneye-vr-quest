GoldenEye VR

Instale o aplicativo no Quest e jogue com seus amigos por sala e código.

Recebeu este link no celular?

Envie esta página para o navegador dos seus óculos. Entre com a conta Meta do seu Quest e escolha o aparelho.

ABRIR NO MEU QUEST

Se você já está lendo nos óculos, comece pelo passo 1.

1Baixar

O botão abaixo baixa o aplicativo oficial, versão 0.5.13.

BAIXAR APLICATIVO

O pacote da família fica disponível por 24 horas a partir do envio. Na página de transferência, pressione “Descarregar ficheiro”.

2Instalar nos óculos

Abra os Downloads do navegador. No arquivo baixado, toque nos três pontos ⋮ e escolha Abrir com → Instalador de pacotes → Instalar. Se o menu mostrar Exportar, use essa opção para abrir a escolha do instalador.

A confirmação é feita no Quest. Se essas opções não aparecerem, o método depende da versão do sistema; baixar o arquivo sozinho não instala o jogo.

Como você já tem SideQuest nos óculos, também pode abri-lo e procurar GoldenEye VR para instalar a versão oficial.

3Abrir e jogar

Biblioteca → Fontes desconhecidas → GoldenEye VR

Na primeira abertura, use Choose ROM file… e selecione sua ROM USA do GoldenEye 007. Escolha Stereo VR.

Uma linha “ROM: GoldenEye 007 (USA) — OK” significa que o jogo já foi reconhecido.

Jogar junto

No painel inicial, antes de START, pressione Play → Multiplayer….

Criar sala
Host → Lobby → Private game → Start Hosting. Envie aos amigos o código que aparecer.

Entrar na sala
Join → Private → digitar o código → Ready.

Começar a partida
Quem criou a sala aperta Launch quando todos estiverem prontos.

O multiplayer é experimental. A partida entre os dois Quests ainda precisa ser testada.
