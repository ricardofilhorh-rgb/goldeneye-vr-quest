1. Abra esta página e toque no botão acima para baixar o APK.
2. No Quest, abra os **Downloads do navegador**, toque nos **três pontos ⋮** junto ao APK e use **Abrir com → Instalador de pacotes → Instalar**. Se aparecer **Exportar**, use essa opção para abrir a escolha do instalador. A disponibilidade depende da versão do sistema; se faltar essa opção, siga o [passo a passo do SideQuest](COMO-INSTALAR.md).
3. Abra **GoldenEye VR** na biblioteca ou em **Fontes desconhecidas**.
4. Na primeira abertura, escolha sua **ROM GoldenEye 007 USA** em **Choose ROM file...**. O APK não inclui os dados do cartucho; cada jogador precisa da própria ROM.
5. Marque **Stereo VR (3D play)** para jogar dentro do mundo em 3D.

## Jogar com um amigo

Use o painel inicial **GoldenEye VR**, com as abas **Play / Controls / Comfort / Screen**, antes de apertar **START**.

| Quero… | O que apertar |
|---|---|
| **Criar minha sala** | **Play → Multiplayer... → Host → Lobby → Private game → Start Hosting** |
| **Convidar meu amigo** | Enviar a ele o **código da sala** que aparecer |
| **Entrar na sala do amigo** | **Multiplayer... → Join → Private**, digitar o código e marcar **Ready** |
| **Começar** | Quem criou a sala aperta **Launch** quando os jogadores estiverem prontos |

**Deathmatch** é o combate entre jogadores (até oito). **Co-op mission** é a campanha juntos (até quatro). Todos devem instalar a mesma versão para facilitar a compatibilidade.

Se aparecer o menu **“1. Select mission / 2. Multiplayer”** com Multiplayer cinza, volte ao painel VR: segure **☰ Menu no controle esquerdo por 1,5 segundo** e confirme com **A no controle direito**. A entrada das salas fica em **Play → Multiplayer...** no painel inicial.
